# ShoppingCartBuilder
Write a function build_cart() that repeatedly asks the user for an item name and price until they type "done". Store items in a dict {item: price}. Print the cart and the total using a separate function cart_total(cart).
<br>
Topics Covered:
1. input()
2. Functions (def)
3. Dictionary ({})
4. while loop
5. if condition
6. break
7. return
8. sum()
9. .items()
10. .values()
11. .lower()
12. float()
13. F-string (f"")
